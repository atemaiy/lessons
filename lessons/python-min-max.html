Рекорды

Что останется на табло?

Игроки набрали 6, 2 и 8 очков.

628

Как запомнить лучший результат?

Текущий максимум

?

Сначала 6. После 2 рекорд не меняется. После 8 новый рекорд равен 8.

Вспомним while

Ноль завершает ввод

x = int(input())
while x != 0:
    print(x)
    x = int(input())

Каждое число вводится с новой строки.

Условие x != 0 проверяется перед телом цикла.

Что случится без последнего input()?

При ненулевом x цикл будет бесконечно печатать одно и то же число.

Переменные

Две переменные для рекордов

Минимум · mn

Самое маленькое из уже прочитанных чисел.

if x < mn:
    mn = x

Максимум · mx

Самое большое из уже прочитанных чисел.

if x > mx:
    mx = x

Начальные значения

Первое число задаёт оба рекорда

6

Пока прочитано одно число, оно и самое маленькое, и самое большое.

x = int(input())
mn = x
mx = x

Частая ошибка

Почему mx = 0 не подходит?

−8−3

Ни одно число не больше нуля. Переменная mx так и останется равной 0.

Но нуля среди данных нет.

Максимум этого потока

−3

Начальное значение рекорда берём из самого потока.

Один рекорд

Поиск в потоке до нуля

mx = int(input())
x = int(input())
while x != 0:
    # сравнение и обновление mx
    x = int(input())
print(mx)

Первый ввод задаёт рекорд.

Цикл обрабатывает следующие числа, пока не встретит 0.

Итоговый вывод находится после цикла.

Минимум и максимум

Один поток, две проверки

if x > mx:
    mx = x
if x < mn:
    mn = x

mn и mx начинаются с первого числа.

Каждое следующее число сравнивается с обоими рекордами.

После цикла:

print(mx, mn)

Проверка алгоритма

А если число только одно?

6, затем 0

Минимум и максимум равны 6.

4, 4, 4, затем 0

Оба рекорда равны 4.

Если первым пришёл 0, данных нет. У пустого потока нет минимума и максимума. В наших задачах поток непустой.

При равенстве рекорд не обновляется. Поэтому сохраняется первая позиция.

if x > mx:
    mx = x

i — текущий индекс, pos — индекс рекорда. Счёт начинается с 0.

Главное

Рекорды хранятся в переменных

Начальные значения — первое число.

Новое число улучшает рекорд только при строгом сравнении.

Ноль завершает поток. Итог выводится после цикла.

После каждого шага

mn и mx — минимум и максимум среди всех прочитанных данных.

Для поиска достаточно переменных и while. Список и встроенные min() / max() не нужны.
