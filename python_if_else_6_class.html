Какая погода?

Дано: температура temperature = 15. При 25 °C и выше считаем, что «Жарко»; от 10 до 24 °C — «Прохладно»; ниже 10 °C — «Холодно». Что сделать: выберите и выведите один результат с помощью if / elif / else.

Python проверяет условия сверху вниз
🔎
temperature = 15

if temperature >= 25:
    print("Жарко")
elif temperature >= 10:
    print("Прохладно")
else:
    print("Холодно")

65–77 минут · elif и вложенные условия

Первые две задачи закрепляют порядок if → elif → else. В третьей нарисуйте два яруса отступов и проговорите: внутренняя проверка запускается только после внешней.

Короткая запись

Тернарный оператор — if / else в одну строку

Обычная запись

if money >= 100:
    msg = "Да"
else:
    msg = "Нет"
→

В одну строку

msg = "Да" if money >= 100 else "Нет"

print(msg)
значение_если_да if условие else значение_если_нет

77–82 минуты · Тернарный оператор

Покажите связь с обычным if/else. Подчеркните: короткую запись удобно использовать только для простого выбора значения; сложные программы лучше оставлять многострочными.

Разбор синтаксиса

Как работает тернарный оператор

msg = "Да" if money >= 100 else "Нет"
1 Проверяем условие

money >= 100 даёт True или False.

→
2А Если True

Берём значение слева от if: строку "Да".

или
2Б Если False

Берём значение после else: строку "Нет".

money = 120 → msg = "Да"   ·   money = 60 → msg = "Нет"

Тепло или холодно?

Дано: температура temp = 18. Значение 15 °C и выше считаем тёплой погодой. Что сделать: одним тернарным выражением запишите в переменную msg строку «Тепло», если условие истинно, иначе — «Холодно». Затем выведите msg.

Оценка и бонус

Дано: score = 82 и bonus = True. От 90 баллов — оценка 5, от 70 — 4, иначе — 3. Что сделать: цепочкой if / elif / else запишите оценку в grade. Тернарным оператором выберите текст «с бонусом» или «без бонуса», затем выведите оба значения.

Сначала выберите оценку,
затем — подпись о бонусе
🧩
score = 82
bonus = True

if score >= 90:
    grade = 5
elif score >= 70:
    grade = 4
else:
    grade = 3

text = "с бонусом" if bonus else "без бонуса"
