# Уроки программирования

Статический сайт с интерактивными HTML-уроками. Главная страница содержит каталог, а каждый урок открывается как отдельная автономная страница.

## Структура

```text
.
├── .github/workflows/deploy-pages.yml  # автоматическая публикация
├── assets/css/site.css                 # стили каталога
├── lessons/                            # HTML-страницы уроков
├── .nojekyll                           # публикация файлов без обработки Jekyll
├── index.html                          # главная страница-каталог
└── README.md
```

## Как опубликовать

1. Отправьте изменения в ветку `main` на GitHub.
2. Откройте в репозитории **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Дождитесь завершения процесса **Deploy lessons to GitHub Pages** на вкладке **Actions**.

После первой публикации сайт будет доступен по адресу:

```text
https://atemaiy.github.io/lessons/
```

## Как добавить урок

1. Поместите новую HTML-страницу в папку `lessons/`.
2. Добавьте для неё карточку в `index.html` внутри блока `.lesson-grid`.
3. Используйте относительную ссылку вида `./lessons/имя-файла.html`, чтобы сайт одинаково работал локально и на GitHub Pages.

Для локальной проверки можно открыть `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Урок о минимуме и максимуме

`lessons/python-min-max.html` — автономная презентация для 6–8 классов:
24 последовательных слайда с теорией, пошаговыми примерами, задачами № 1–9,
тестами № 4 и домашним заданием. Стрелки переключают слайды, пробел раскрывает
ответ или следующий шаг примера, F включает полноэкранный режим. На слайдах нет
тайминга, таймера, боковой панели и методических инструкций.

`output/pdf/minmax-solutions.pdf` — отдельный ключ преподавателя с решениями
№ 1–9 и Д1, пояснениями и тестами. Файл хранится отдельно от детской презентации.

Источник условий и тайминга — предоставленный план Полищука; методическая
основа находится в `knowledge-base/`. Данные задач и генератор PDF:
`scripts/minmax_materials.py`, генератор слайдов: `scripts/minmax_deck.py`.
Для пересборки запустите `python scripts/minmax_materials.py` в среде с
ReportLab и шрифтами Arial и Consolas (`C:/Windows/Fonts`). Для проверки решений,
ссылок и страниц PDF — `python scripts/check_minmax.py` (также требуется pypdf).
